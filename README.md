# ⚡ Electrical Learning Chatbot

An NLP-based electrical engineering learning chatbot built using **Python, TF-IDF, Logistic Regression, and Streamlit**.

The chatbot is designed to answer basic electrical engineering questions by identifying the user's question type (intent) and providing a detailed explanation with examples.

---

## 📌 Project Overview

This project uses traditional NLP and machine learning techniques instead of a large language model.

The chatbot learns from a custom electrical engineering dataset.

For example, when the user asks:

> What is voltage?

The NLP model identifies the question as the `voltage` intent and the chatbot provides an explanation such as:

- Definition
- Unit
- Formula, when applicable
- Simple explanation
- Practical example

Example:

```text
Voltage is the electrical potential difference between two points
in a circuit.

Unit: Volt (V)

Example:
A 12 V battery provides a potential difference of 12 volts.
This voltage provides the electrical push that allows current
to flow through a connected circuit.
````

---

# 🧠 NLP Architecture

The chatbot follows this pipeline:

```text
                 User Question
                       │
                       ↓
                Text Input
                       │
                       ↓
              TF-IDF Vectorizer
                       │
                       ↓
            Numerical Representation
                       │
                       ↓
             Logistic Regression
                       │
                       ↓
                Intent Prediction
                       │
              ┌────────┴────────┐
              ↓                 ↓
        Known Intent          Unknown
              │                 │
              ↓                 ↓
       Find Response       Unknown Response
              │
              ↓
        Streamlit UI
              │
              ↓
             User
```

# 📂 Project Structure

```text
electrical_chatbot/
│
├── dataset.json
│
├── train.py
│
├── evaluate.py
│
├── app.py
│
├── model.pkl
│
└── vectorizer.pkl
```

### `dataset.json`

Contains the training data.

Each intent contains:

```text
tag
patterns
responses
```

Example:

```json
{
    "tag": "voltage",
    "patterns": [
        "What is voltage?",
        "Define voltage",
        "Explain voltage"
    ],
    "responses": [
        "Voltage is the electrical potential difference..."
    ]
}
```

---

### `train.py`

Used to train the NLP model.

The training process is:

```text
dataset.json
     ↓
Extract patterns and tags
     ↓
TF-IDF Vectorization
     ↓
Logistic Regression
     ↓
Trained Model
     ↓
model.pkl
vectorizer.pkl
```

---

### `evaluate.py`

Used to evaluate the machine learning model.

It calculates:

* Accuracy
* Precision
* Recall
* F1-score

It also displays incorrectly classified questions.

---

### `app.py`

The Streamlit web application.

It:

1. Loads the trained model.
2. Loads the TF-IDF vectorizer.
3. Accepts user questions.
4. Converts the question into TF-IDF features.
5. Predicts the intent.
6. Checks the prediction probability.
7. Finds the corresponding response.
8. Displays the answer in the web interface.

---

### `model.pkl`

Contains the trained Logistic Regression model.

It is generated by:

```bash
python train.py
```

---

### `vectorizer.pkl`

Contains the trained TF-IDF vectorizer.

It converts user text into the same numerical representation used during training.

# 🎯 Confidence / Unknown Handling

The Logistic Regression model produces a probability for each trained intent.

For example:

```text
voltage      0.86
current      0.02
power        0.02
energy       0.01
resistance   0.02
ohms_law     0.04
unknown      0.03
```

The highest probability is:

```text
voltage = 0.86
```

Therefore, the chatbot predicts:

```text
voltage
```

A threshold is also used to reject predictions with very low probability.

Current experimental threshold:

```text
0.30
```

This threshold is not considered final and should be validated with a larger dataset.

# 🔬 Machine Learning Method

## TF-IDF

TF-IDF converts text into numerical features.

For example:

```text
"What is voltage?"
```

is converted into numerical values that the machine learning model can process.

TF-IDF considers how important words are within the training documents.

---

## Logistic Regression

Logistic Regression is used as the intent classifier.

It receives the TF-IDF representation and predicts one of the trained intents:

```text
voltage
current
resistance
power
energy
ohms_law
unknown
```

---

# 🧪 Training vs Prediction

Training happens when:

```bash
python train.py
```

The model learns from:

```text
patterns → intents
```

The trained model is saved as:

```text
model.pkl
vectorizer.pkl
```

During chatbot usage, the model is not retrained.

Instead:

```text
User Question
     ↓
TF-IDF
     ↓
Existing Model
     ↓
Intent
     ↓
Response
```
